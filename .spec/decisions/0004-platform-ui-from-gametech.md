# 0004 · 平台网页视觉继承 GameTech 身份色与品牌标，不搬视频画布与白板主题

- 日期:2026-09-04
- 状态:生效

## 背景

`LumioVideoWorkFlow/design-system`（`@lumio/video-ds`）是 Lumio 已落地的视觉库，但目标是 HTML 动画页：固定画幅、远看字阶、无指针。本仓要做的是浏览器里的大厅 / 账号 / 反馈 / 后台。另有游戏美术三方向比稿（暖软绘本 / 明快硬描边 / 玩具质感），尚未定调，不能当平台壳。

视频 DS 内部已有两套主题：默认白板（短视频母题）与 GameTech（从 `blog.lumio.games` 按观看距离放大）。GitHub 组织页徽章已经在用 GameTech 的 `#6171F0` / `#5DE2C6`。

## 决策

- 平台 SPA 的身份色、纸片卡片配方、品牌像素标，只继承 GameTech / 博客那一套，写进 `web/src/styles/`，变量前缀 `--ui-*`，类名 `.ui-*`。
- 字阶、间距、圆角、动效时长按 16px 网页重定；补表单、焦点、表格、空状态。不把 `@lumio/video-ds` 当 npm 依赖，不搬 `Stage` / `Deck` / `Reveal` 及白板主题。
- 游戏内美术比稿不锁进平台壳；大厅封面与默认头像可以长得像玩具盒，平台铬（顶栏、表单、后台）保持 GameTech。
- 不引入 UI 框架。令牌全局引入一次，功能布局用 CSS Modules。

## 后果

- 平台壳是冷色纸面 + 紫/薄荷强调，和游戏里将来可能的奶油暖色可以并存：进游戏等于离开平台铬。
- 视频仓改 GameTech 色板时，本仓令牌要人工同步（两仓不共享包）。
- P0-1 脚手架不得覆盖已入库的 `web/src/styles/` 与 `web/design-preview.html`。
